How to use this tool

  1. Paste or type a value in the input panel, or load a local file.
  2. Choose the action above. Errors appear here with details from the browser parser where available.
  3. Review the generated result before copying or downloading it.

Examples and limitations

Use the example button to see a representative input. JSON syntax is strict: property names and strings use double quotes, and comments and trailing commas are not part of standard JSON. Input is processed locally in the page. This tool does not send your JSON to a conversion API.
