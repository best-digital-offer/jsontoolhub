Privacy and practical limits

Inputs are handled by JavaScript in your current browser page. They are not placed in a URL or sent to a conversion service. Avoid pasting secrets into any online tool. Some conversions, especially from nested JSON to CSV, require choices because CSV is a flat table format.

JSON Schema and JSON-LD pages explain which checks are supported and which standards features they do not cover. Review output before using it in production.
